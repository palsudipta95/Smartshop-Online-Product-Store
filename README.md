Tech_Commerce

A simple e-commerce web project developed for the course CSE-3532.
The project demonstrates how product data can be fetched from local JSON files and dynamically displayed on web pages using JavaScript APIs.


---

📌 Project Overview

Tech_Commerce is a front-end based e-commerce website project built using:

HTML

Tailwind CSS

DaisyUI

JavaScript


The main objective of this project is to practice:

Working with local JSON data

Fetching and displaying data dynamically

Building responsive UI components

Using modern CSS frameworks and templates



---

🚀 Features

Dynamic product rendering from local JSON files

Responsive user interface

Modern UI using Tailwind CSS and DaisyUI

Clean product card layouts

JavaScript-based data handling

Beginner-friendly project structure

⚙️ How It Works

1. Product information is stored inside local JSON files.


2. JavaScript fetches the JSON data.


3. The fetched data is dynamically inserted into HTML elements.


4. Tailwind CSS and DaisyUI are used to style the UI components.




---

▶️ How to Run the Project

1. Clone the repository:



git clone <repository-link>

2. Open the project folder.


3. Run the project using a local server
(Recommended: VS Code Live Server extension).


4. Open index.html in your browser.
